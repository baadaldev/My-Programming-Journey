## 🚀 Projects Showcase (C Language)

### 1. 🏥 Hospital Management System (`C/08-Projects/Hospital-Management-System`)
A terminal-based database system for hospital administration.
* **Features:**
  * Role-based authentication (**Admin** and **Moderator**).
  * Add, search, update, and manage patient records with disease history, attending doctor, guardian details, and blood group.
  * ANSI color-coded modern terminal interface.
  * Persistent file storage (`patients.txt` and `users.txt`).

### 2. 📝 Quiz & Examination System (`C/08-Projects/Quiz-Examination-System`)
An examination portal with dual roles for teachers and students.
* **Features:**
  * Admin role for adding questions, defining multiple-choice options, and setting answer keys.
  * Student login to participate in timed exams with automatic score calculation.
  * Result log export (`results.txt`).

### 3. ⏱️ Task & Todo Manager (`C/08-Projects/Task-Todo-Manager`)
A CLI productivity and task scheduling utility.
* **Features:**
  * Add, complete, and delete tasks.
  * Set deadline timestamps and sort tasks chronologically.
  * Statistical summary of completed vs pending tasks.

### 4. 🎓 Student Record System (`C/08-Projects/Student-Record-System`)
An academic record manager for university coursework.
* **Features:**
  * Store student IDs, full names, and CGPAs.
  * Search, view, and update student profiles dynamically.

### 5. 🚆 Train Ticket System (`C/08-Projects/Train-Ticket-System`)
A railway reservation simulator handling seat allocations and ticket generation.

## 🛠️ How to Compile & Run

### For C Programs:
```bash
# Compile using GCC
gcc filename.c -o program

# Run executable
./program        # Linux/macOS
.\program.exe    # Windows
```

### For C++ Programs:
```bash
# Compile using G++
g++ filename.cpp -o program
.\program.exe
```

### For Java:
```bash
javac filename.java
java ClassName
```

### For Python:
```bash
python filename.py
```

### For Web / HTML:
Open any `.html` file directly in any modern web browser (Google Chrome, Firefox, Edge).
